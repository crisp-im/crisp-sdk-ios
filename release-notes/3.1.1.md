# Crisp iOS SDK 3.1.1

This release fixes what the SDK reports about the current session.

## Changes

- `CrispSDK.session.identifier` now returns the session identifier once the
  session has loaded, including inside the `sessionLoaded` callback.
- `CrispSDK.session.isOngoing` now reports whether messages have been
  exchanged in the session.
- A session reset requested while the chat is still loading no longer
  reports the previous session as loaded before switching.
