# Crisp iOS SDK 3.0.1

This release improves the security of chat sessions. We recommend that all
apps upgrade.

## Changes

- Chat sessions are now tied to a token issued by Crisp, so only the
  device that started a conversation can reopen it.

## Upgrading

- No code changes are needed.
- Crisp will start requiring these tokens in the coming months. After
  that, older SDK versions won't be able to reopen conversations, and
  conversations started before this update will be replaced by a new one.
