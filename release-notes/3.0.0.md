# Crisp iOS SDK 3.0.0 🎉

A brand new SDK, rebuilt from the ground up. Same chatbox your users love,
a much lighter footprint in your app.

## ✨ Highlights

- **Audio & video calls with no extra baggage.** The separate `CrispWebRTC`
  product and the bundled WebRTC framework are gone. Calls just work.
- **Always in sync with the web chatbox.** New Crisp chatbox features reach
  your app faster.
- **Catch configuration mistakes early.** Missing Info.plist usage
  descriptions are reported up front instead of crashing mid-conversation.

## 🧳 Upgrading from 2.x

- Minimum deployment target is now **iOS 14** (was iOS 13).
- Requires **Xcode 16.3+** (Swift tools 6.1).
- Remove the `CrispWebRTC` product (SPM) or `Crisp/CrispWebRTC` subspec
  (CocoaPods) from your dependencies. It's no longer needed.
- If required Info.plist keys are missing, the chat won't start. You can
  opt out with `CrispSDK.unsafeDisableMissingUsageDescriptionWarnings()`.

## ⚠️ CocoaPods is deprecated

We will stop publishing to CocoaPods at the end of September 2026. Please
migrate to Swift Package Manager.
