# Crisp iOS SDK 3.1.0

This release adds a color mode setting and fixes how sessions are switched
on login and logout.

## Changes

- `ChatViewConfiguration.colorMode` overrides the color mode set in the
  Crisp dashboard (`.light`, `.dark` or `.auto`).
- The loading animation was refreshed and no longer flashes on fast loads.
- After a login, the chat now opens directly into the user's conversation.
- After a logout, the previous conversation no longer comes back if the
  app was quit before the chat was opened again.
- A registered device token now moves to the new session after a reset.
